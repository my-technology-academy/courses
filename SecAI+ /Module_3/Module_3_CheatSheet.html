SecAI+ CY0-001: AI-assisted Security

3.1 AI-ENABLED TOOLS
Forms: IDE/browser/CLI plug-ins, chatbots, personal assistants, MCP server
Use cases: signature matching, linting, vulnerability analysis, automated pen testing, anomaly detection, pattern recognition, incident management, threat modelling, fraud detection, translation, summarisation
3.2 AI ATTACK VECTORS
Deepfakes (impersonation/misinfo/disinfo)
Adversarial networks
Reconnaissance & social engineering
Obfuscation
Automated data correlation
Automated attack generation
DDoS
3.3 AUTOMATING SECURITY TASKS
Low-code/no-code scripting
Document synthesis & summarisation
Incident response ticket management
Change management (AI approvals, auto deploy/rollback)
AI agents
CI/CD (code scanning, SCA, testing, model testing)
3.1 vs 3.2 vs 3.3 — THE KEY DISTINCTION
ObjectiveWho Benefits
3.1AI assists a human defender
3.2AI assists an attacker
3.3AI replaces a manual defensive process end to end
MCP SERVER
Standardised interface for a model to discover/call external tools
Centralises agent/tool access — ties to Domain 2.0 agent access controls
EXAM TRAPS
Automation (3.3) removes the human; assistance (3.1) keeps a human deciding
Deepfakes are AI-generated content, not a standalone "hacking" technique
