UKAIF: Module 1

1.1 CORE DEFINITION
AI: performs tasks needing human intelligence; learns from data
Automation: fixed rules; never adapts without a rewrite
Quick test: could a fixed if-this-then-that rule replace it? If yes → automation
1.2 THE HIERARCHY
Nesting: AI ⊃ Machine Learning ⊃ Deep Learning
Generative AI: deep-learning systems that create new content, not a 4th separate layer
Watch for: more parameters ≠ smarter or more general
1.4 NARROW VS GENERAL
Narrow AI: built for one task or family of tasks — every system today
General AI (AGI): human-like, any-task intelligence — hypothetical, does not exist
Watch for: fluent output ≠ general intelligence
1.3 CORE VOCABULARY
TermMeaning
ModelThe trained, reusable output of the training process
DatasetThe examples used to train or evaluate a model
ParametersInternal values a model adjusts during training
TokensSmall chunks of text a model reads and generates

LLMA foundation model specialised in text
Multimodal AIWorks across more than one content type
EmbeddingsMeaning represented numerically, for comparison and retrieval
1.5 PREDICTIVE VS GENERATIVE
PredictiveGenerative
Outputs a score or labelOutputs new content
"What is this / will happen?""Create something new"
EXAM TRAPS & ACRONYMS
⚠️ "AI" and "automation" are not the same — automation follows fixed rules
⚠️ Generative AI is not the only type of AI — predictive/analytical AI is just as common
⚠️ More parameters ≠ smarter or more general — still narrow AI
⚠️ General AI (AGI) does not exist yet, however fluent a chatbot seems
