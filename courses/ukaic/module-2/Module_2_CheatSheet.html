UKAIC: Module 2

2.1 PREDICTION
Core idea: output is the most likely result, not a lookup
LLM loop: prompt → tokens → predict next token → append → repeat
Watch for: prediction ≠ retrieval — seed of hallucination (Module 6)
2.2 TRAINING VS INFERENCE
Training: builds the model, once/periodically, from data
Inference: using the trained model — every single prompt
Watch for: normal use does not retrain the model
2.3 DATA & PARAMETERS
Datasets: a model only reflects patterns in its training data
Parameters: internal values tuned during training
Watch for: more parameters ≠ automatically smarter
2.4 & 2.5 — TWO DIFFERENT LIMITS
Context WindowKnowledge Cut-off
LimitsText length + conversation memoryCurrency of information
FixNew conversation / summariseConnect to current external info
2.6 TEMPERATURE
SettingSuited To
LowFacts, code — focused & repeatable
HighBrainstorming, creative writing
Non-determinism: same prompt, different plausible replies — normal, not a fault.
2.7 APIS & EMBEDDINGS
API: lets applications call a model without a chat window
Embeddings: meaning represented numerically, for comparison
EXAM TRAPS
⚠️ A model "looks up" facts — it predicts likely output; it does not query a stored fact table
⚠️ Using a chatbot a lot retrains or personalises it — ordinary use is inference only
⚠️ Different answers to the same question means something is broken — non-determinism is normal
⚠️ Knowledge cut-off and context window are the same limit — they are not; one is about time, the other about conversation length
