The Takeaway

Four habits that improve every prompt you write.

  • 01Task, context, format, constraints.Before you send anything, ask which of the four is missing. That one question does most of the work.
  • 02A role and a named reader cost one sentence each.They set expertise, vocabulary and register — and a focused short prompt beats a rambling long one.
  • 03Show it, or split it.Give an example when showing is faster than describing. Break a request into ordered steps when you are asking for several things at once.
  • 04The first output is a draft.Follow up with corrections you can check afterwards — a word count, a section removed, a closing line named. Not "make it better".
