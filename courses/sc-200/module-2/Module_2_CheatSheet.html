2.1 WHICH PRODUCT OWNS WHICH SIGNAL?

2.1 INVESTIGATION TECHNIQUES
Agentic AI / Security Copilot: summarise incidents, explain scripts, generate KQL, recommend actions
Complex attacks: multi-stage (phases) · multi-domain (email+identity+endpoint+apps) · lateral movement (pivoting)
Case management: ownership, status, evidence, tasks, notes — auditable handovers
2.2 DEFENDER FOR ENDPOINT RESPONSE
Device timeline: processes, files, registry, network, logons — what ran & what it touched
Containment: isolate device · restrict app execution · AV scan
Live response: interactive remote shell
Investigation package: forensic artefact bundle for offline analysis
Evidence/entities: files, processes, IPs, URLs, users, devices + verdicts
2.3 M365 INVESTIGATION — PICK THE RIGHT TOOL

EXAM TRAPS & PRODUCT ACRONYMS
⚠️ Entra ID ≠ Defender for Identity — cloud identity risk vs on-prem domain attacks (keywords: DC, Kerberos, LSASS → MDI)
⚠️ Audit returns actions; Content search returns content — they answer different questions
⚠️ Defender for Cloud workload protection alerts = runtime threats, not posture recommendations
⚠️ Attack disruption containing an attack does NOT close the incident — persistence can survive containment
⚠️ Password reset without revoking tokens can leave the attacker's session alive
