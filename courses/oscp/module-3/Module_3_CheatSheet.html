OSCP: Effective Learning Strategies

3.1 LEARNING THEORY
Memory: encode → store → retrieve. Only retrieval is trainable and tested
Dual encoding: verbal + visual together beat either alone
Curve of Forgetting: retention decays fast without intervention
Cognitive load: working memory is small; overload halts learning
3.2 UNIQUE CHALLENGES
Digital material: searchable & executable, but access ≠ competence
Unknown scenarios: method transfers, specific sequences do not
Remote study: no external pace, no immediate correction, isolation feels personal but is structural
3.3 / 3.4 METHODOLOGY
Demonstrative Methodology: shows reasoning, requires the learner to extend it — not a procedure to copy
chmod -x chmod: case study in expanding beyond the given information set
The move: restate precisely → question assumptions → widen the information set → test and let failure narrow the next attempt
3.5 NAMED TACTICS AND COMMON METHODS
Technique Use it when What it exercises
Retrieval PracticeMaterial has been read and needs to become usableRecall under effort — the tested phase
Spaced PracticeMaterial must survive weeks or monthsDurability against the Curve of Forgetting

3.6 EXAMS
Stress: a performance variable — rehearse conditions, pre-decide your routine
Readiness: unaided performance on unseen material, not confidence or completion
Approach: enumerate → timebox → document continuously → rotate back with new information
3.7 PRACTICAL STEPS
Long-term strategy: plan in modules and retrieval states, not hours
Time allotment: fixed blocks, decided in advance, treated as real
Narrow focus: only after breadth shows where the evidence points
Co-learners: correction, calibration, and a live Feynman partner
EXAM TRAPS & ACRONYMS
⚠️ Re-reading is not studying — it exercises recognition, not the retrieval that is actually tested
⚠️ Difficulty during recall is the mechanism working, not evidence it is failing
⚠️ Dual encoding ≠ "learning styles" — two channels help everyone, it doesn't license dropping either one
⚠️ Diagnose before treating: forgetting responds to spaced retrieval; overload responds to breaking material down
⚠️ Readiness is evidenced (unaided recall on unseen material), never merely felt
⚠️ Narrow focus only after broad enumeration — never because an avenue is simply comfortable
