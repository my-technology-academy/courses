9.3 MANUAL & AUTOMATED CODE EXECUTION
xp_cmdshell: MSSQL extended procedure running OS commands with the DB service's privileges — disabled by default on modern installs
'; EXEC xp_cmdshell 'whoami';--
SQLmap: automates UNION/error/blind detection and exploitation across engines — use AFTER manual confirmation, never as the first probe
Discipline: confirm manually → fingerprint engine → automate for scale → verify the automated result manually before reporting
EXAM TRAPS & ACRONYMS
⚠️ No visible error ≠ no injection — it means the error/UNION channels are closed; try Blind techniques
⚠️ UNION requires matching column count AND compatible data types
⚠️ xp_cmdshell is disabled by default on modern MSSQL — re-enabling usually needs elevated privilege already
⚠️ SQLmap does not replace understanding SQLi — it automates what you must first confirm manually
⚠️ Fingerprint the engine before writing payloads — MySQL and MSSQL syntax genuinely differ
