16.1 ENUMERATING LINUX & 16.2 EXPOSED CREDENTIALS
Permission model: rwx per owner/group/other + special bits
Shell history: credentials typed as command arguments
User trails: configs, saved sessions — one user's activity
System trails: host-wide logs/configs — other accounts' creds
find / -perm -4000 -type f 2>/dev/null
16.3 FILE PERMISSIONS & 16.4 SYSTEM COMPONENTS
Cron jobs: privileged job executing a writable script
File permissions: any writable file trusted by a privileged process
SUID/capabilities: runs as owner — exploit unintended actions
Sudo: permitted commands manipulated via args into root shell
Kernel: version vs known, documented vulnerabilities

⚠️ Not every SUID binary is exploitable — it must permit an unintended action
