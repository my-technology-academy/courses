OSCP: Windows Privilege Escalation

15.1 ENUMERATING WINDOWS
Situational awareness: user, privileges, software, processes, patch level
Sensitive info: configs, scripts, unattended install files, stored creds
PowerShell: history & transcripts — often hold admin credentials
Automated tools: accelerate enumeration — ALWAYS verify manually
15.2 LEVERAGING WINDOWS SERVICES
TechniqueRequires
Binary hijackWrite access to the service .exe itself
DLL hijackWrite access earlier in the DLL search order
Unquoted pathWritable earlier segment of an unquoted, spaced path
C:\\Program Files\\My App\\service.exe (unquoted)
tries: C:\\Program.exe → C:\\Program Files\\My.exe → intended
15.3 ABUSING OTHER WINDOWS COMPONENTS
Scheduled Tasks
Privileged task executing a modifiable script/binary — same logic as services, on a timer
Known exploits
Kernel or third-party service vulnerabilities — independent of misconfiguration (link: Modules 11/12)
Privilege abuse
A held privilege permitting privileged execution directly — no exploit needed
EXAM TRAPS & ACRONYMS
⚠️ DLL hijacking ≠ unquoted path abuse — one targets a library, the other targets how Windows parses spaced paths
⚠️ Automated tool output is a candidate, not a confirmed finding — verify manually every time
⚠️ Escalation doesn't always need an exploit — misconfiguration and overly broad privileges are just as valid
⚠️ Check PowerShell history/transcripts for ALL accessible profiles, not just the current user
⚠️ Confirm restart/trigger conditions before planting replacement content — don't disrupt availability
