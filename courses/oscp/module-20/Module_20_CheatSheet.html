OSCP: Active Directory Introduction and Enumeration

20.1 MANUAL ENUMERATION
Legacy applications: built-in, already present, no new tooling needed
PowerShell/.NET: flexible, scriptable, direct programmatic access
20.2 EXPANDING THE REPERTOIRE
OS perms/logged-on users: local host context, active accounts
SPNs: service accounts — foundation for Module 21 Kerberoasting
Object permissions: fine-grained control, independent of groups
Domain shares: often the richest single credential source
20.3 AUTOMATED ENUMERATION
SharpHound: collects raw domain relationship data (users, groups, sessions, permissions) at scale — automates 20.1/20.2 manually
BloodHound: visualises that data as a graph, surfacing attack paths to high-value targets — VERIFY the underlying permission before acting
Watch: a full SharpHound sweep generates real traffic/logging noise — weigh against engagement stealth needs
