14.2 CRACKING FUNDAMENTALS
Offline: no lockout/rate-limit — needs captured material first
Dictionary → Rule-based → Brute force: speed vs. coverage trade-off
Named targets: mutated wordlists, password manager key files, SSH key passphrases
password → Password1! → P@ssw0rd

EXAM TRAPS & ACRONYMS
⚠️ NTLM (at rest) ≠ Net-NTLMv2 (over the network) — different capture methods, different techniques
⚠️ NTLM can be PASSED directly; Net-NTLMv2 is RELAYED — not interchangeable terms
⚠️ An uncracked hash is not a dead end — passing/relaying works without the plaintext
⚠️ Always respect account lockout policy during live login attacks — scope violations start here
⚠️ Time-box cracking attempts before defaulting to pass/relay — don't over-invest
