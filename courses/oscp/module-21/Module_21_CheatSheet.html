OSCP: Attacking Active Directory Authentication

21.1 UNDERSTANDING AUTHENTICATION
ProtocolBasisRelated attacks
NTLMChallenge-response, password hashPass-the-hash, relay (M14)
KerberosTickets from a trusted authorityKerberoasting, forging (M21)
Cached AD credentials: local material enabling offline login — also a fresh hunting ground on domain-joined machines
21.2 THE ESCALATION LADDER
1. Password attacks → one valid domain credential
2. Account option abuse → weakened account auth
3. Kerberoasting → SPN → ticket → crack hash offline
4. Forging service tickets → fabricated access
5. DC impersonation → any domain credential (most severe)
EXAM TRAPS & ACRONYMS
⚠️ NTLM and Kerberos are NOT interchangeable — distinct mechanisms, distinct attacks
⚠️ Kerberoasting needs NO admin privilege — any authenticated user can request an SPN's ticket
⚠️ Kerberoasting (crack a legit ticket) ≠ Forging (fabricate one directly) — different mechanisms
⚠️ SPN enumeration (Module 20) is the PREREQUISITE for Kerberoasting — can't roast what you haven't found
⚠️ DC impersonation is the module's ceiling — confirm scope explicitly before attempting it
