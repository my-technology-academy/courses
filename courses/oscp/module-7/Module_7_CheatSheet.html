OSCP: Introduction to Web Applications

7.1 ASSESSMENT METHODOLOGY
Black box: no prior knowledge or credentials
Grey box: partial knowledge, limited credentials
White box: full access incl. source code
OWASP Top 10: reference map, NOT the course's actual scope
7.2 TOOLS
Proxy: sits between browser/app, removes browser's own limits
Burp Proxy: intercept traffic live
Burp Repeater: resend + edit one request
Burp Intruder: automate many variations of a request
7.3 ENUMERATION
Source code: reveals bypassable client-side validation, hidden fields, comments
Headers: versions, missing security headers
Cookies: session structure, script/transport flags
APIs: often weaker validation than the UI on top
7.4 CROSS-SITE SCRIPTING (XSS)
TypeMechanismRequires
ReflectedPayload travels in the request, echoed straight backVictim clicks a crafted link
StoredPayload saved server-side, served to every visitorNothing — automatic exposure
DOM-basedClient-side JS unsafely inserts attacker dataNever reaches the server
Proof-of-existence payload: <script>alert(document.cookie)</script> · Privilege escalation via XSS: a script in a victim's session acts with that victim's privileges — impact depends entirely on whose session runs it.
EXAM TRAPS & ACRONYMS
⚠️ XSS is not "always low severity" — impact depends on whose session runs the payload
⚠️ Reflected needs a crafted link; stored needs nothing — every visitor is exposed
⚠️ Client-side validation is NOT a real control — a proxy bypasses it entirely
⚠️ Black box is about ACCESS LEVEL, not which tools are permitted
⚠️ The OWASP Top 10 is a reference map, not the course's actual scope of record
