OSAI: Attacking Multi-Agent Systems and A2A Protocols

4.1 ARCHITECTURE FUNDAMENTALS
Multi-agent: a second agent's own reasoning step consumes the first's output
Topologies: orchestrator-led, peer swarm, hierarchical delegation chain
New trust boundary: exists at every agent-to-agent hand-off
Building blocks: orchestrator, specialists, shared state, message channel
Extends: Module 1's agent/tool layer; Module 3's single-agent findings
4.2 INTER-AGENT MESSAGE POISONING
Definition: indirect injection applied at agent-to-agent scale
Entry points: relayed summaries, sub-agent output, shared-state writes
Cascade: compromise → survives to output → trusted hand-off → re-executes → propagates
Root cause: cooperative-by-default design, no re-validation at hand-offs
Maps to: OWASP LLM01, LLM06, ATLAS lateral-movement-style progression
4.3 A2A PROTOCOL CONCEPTS
Discovery: one agent locates another that might help
Capability advertisement: an agent's own declared claim of what it can do
Delegation: a task, with context, formally handed to another agent
Trust assumption: declared identity/capability accepted, rarely verified
Scope: general concepts only — no invented field names or versions

4.4 AGENT TRUST & DELEGATION EXPLOITATION — ENUMERATION METHOD
1 List every agent in the chain 2 Record each agent's privilege 3 Map each hand-off & re-validation 4 Locate the privilege ceiling 5 Trace lowest-to-highest privilege path Principle: autonomy raises blast radius (Module 1) — multiplied by every agent and hand-off
EXAM TRAPS & ACRONYMS
⚠️ Multi-agent is not "one agent with more tools" — it requires a second independent reasoning step
⚠️ Message poisoning is not a new primitive — it is Module 1's indirect injection at agent-to-agent scale
⚠️ Never invent A2A field names, message formats, or version claims — use general conceptual language
⚠️ Confused deputy across agents is a social-engineering pattern, not a technical exploit of Agent B's tools
⚠️ Blast radius is set by the most privileged agent in the chain, not the agent the attacker first touches
⚠️ OSAI weightings are not published — the exam is a 24-hour practical engagement
