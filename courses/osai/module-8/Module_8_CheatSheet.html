OSAI: AI Supply Chain Attacks

8.1 THE AI SUPPLY CHAIN
Definition: everything externally sourced, not built in-house
Four categories: model weights, datasets, plugins/tools, ML libraries
Backlink: Module 1 Obj 1.2 supply-chain layer; Module 2 Obj 2.1 OSINT
Direct vs transitive: transitive deps carry the same risk, unreviewed
Why high-leverage: one component, many downstream deployments
Core lesson: trust is inherited, not verified
8.2 MALICIOUS / BACKDOORED MODELS
Backdoor: normal on ordinary input, malicious on an attacker-known trigger
Hard to detect: indistinguishable from clean on nearly all input
vs ordinary flaw: deliberate + conditional vs general + reproducible
Myth: "popular download" measures adoption, not integrity
Verification gap: no practice alone catches a well-hidden trigger
Framework: OWASP LLM03; MITRE ATLAS supply-chain tactic
8.3 UNSAFE DESERIALIZATION
Risk: loading a file — not running it — can execute code
Cause: format reconstructs arbitrary objects, not just numeric weights
Data-only format: cannot execute code on load, by design
General-purpose format: flexible, but code-execution-capable
Mitigate: prefer data-only, sandbox load, verify integrity, least privilege
Framework: OWASP LLM03; co-occurs with, but ≠, Objective 8.2

8.4 DATASET & DEPENDENCY POISONING — LIFECYCLE & ASSESSMENT
1 Identify a popular legitimate package 2 Publish a similarly named malicious package 3 Wait for accidental or automated resolution 4 Malicious code executes on install/import 5 Compromise reaches every install — no targeting needed
VET Dataset provenance before training PIN Package names and versions, verified MIRROR Private or mirrored package sources AUDIT Training-data changes over time
EXAM TRAPS & ACRONYMS
⚠️ A popular public model is not automatically safe — popularity measures adoption, not verification
⚠️ Model files "are just data" is false — some formats execute code during loading itself, before inference
⚠️ Dataset poisoning ≠ RAG-corpus poisoning — training-time weight change vs retrieval-time content change
⚠️ Dependency confusion needs no targeted victim — a typo or misconfigured source is enough
⚠️ Backdoor behaviour is deliberate and trigger-conditioned — do not confuse it with an ordinary model flaw
⚠️ OSAI weightings are not published — the exam is a 24-hour practical engagement
